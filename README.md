# 🎬 NLP Workshop — AI Club Datathon Prep

A hands-on workshop introducing Natural Language Processing (NLP) 
using the IMDB Movie Reviews dataset. Built for the AI Club Datathon 
to prepare members for working with real-world text datasets.

## 📚 What You'll Learn
- How to clean and preprocess raw text data
- How to turn words into numbers using Bag of Words and TF-IDF
- How to train and compare sentiment classifiers with scikit-learn
- How to evaluate models beyond just accuracy
- How to interpret what your model actually learned

## 🛠️ Tools & Libraries
- Python
- NLTK
- Scikit-learn
- Pandas
- Matplotlib
- WordCloud
